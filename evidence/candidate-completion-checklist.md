# Publication checklist (external steps only)

The proposal is prepared using the information provided. Missing official programme data and field measurements are explicitly disclosed rather than fabricated. These do not need to be invented to publish the desk-based submission.

- [ ] Create one GitHub repository and upload the **contents of the extracted ZIP folder** (README.md at the repository root; do not upload only the ZIP).
- [ ] Make repository viewable to the evaluator; inspect the README and internal links on GitHub.
- [ ] Create a named GitHub release using `round2-v1.0` if that matches the portal instructions.
- [ ] Record the repository URL, the exact full commit URL for the submitted files, and the release URL wherever the portal asks for them. If adding these URLs to README, commit that update and use the correct commit URL.
- [ ] Submit the repository URL through the HKAIVERSE Round 2 portal before **24 October 2026, 11:59 PM IST** and retain confirmation.

Do not claim measured fieldwork, faculty feedback, official total credits, live application tests or deployment.
