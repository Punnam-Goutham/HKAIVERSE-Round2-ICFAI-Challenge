# Task 2 — Job Description Comparison

**Research date:** 24 October 2026  
**Candidate context:** B.Tech CSE student, expected graduation 2027.  
**Method:** Three public job postings were reviewed for recurring skill requirements. Job descriptions can change; links and requirements should be rechecked before final submission. This is a skills comparison, not a claim that the candidate is eligible for every role.

## Job 1 — Amazon, Software Development Engineer, Early Career (2026)

- **Link:** https://www.amazon.jobs/en-gb/jobs/10502743/software-development-engineer-early-career-2026
- **Relevance/caveat:** The posting explicitly targets early-career candidates, but the listed location is Canada. It is used as a software-engineering skills benchmark, not as an India-based vacancy or a claim of geographic eligibility.
- **Requirements highlighted in the posting:** One general-purpose programming language; data structures and algorithms or object-oriented design; preferred experience with internships/projects, AI tools for development productivity, cloud platforms (preferably AWS), SQL/NoSQL databases, version control, debugging and troubleshooting.
- **Curriculum connections:** Computer Programming (CS101), Data Structures (CS102), Design and Analysis of Algorithms (CS203), OOP (CS201), DBMS (CS206), Cloud Computing (CS307), Software Engineering (CS304), Internship I (IP201), Special Project (SP301).
- **Gap/opportunity:** Ensure students complete an end-to-end team project using Git, automated tests, a database, deployment and operational monitoring—not just isolated theory assignments.

## Job 2 — ServiceNow, Software Engineer, Hyderabad

- **Link:** https://careers.servicenow.com/jobs/744000155459130/software-engineer/
- **Posting date shown on current listing:** 14 October 2026.
- **Relevance/caveat:** The current Hyderabad listing describes an IC2 engineer working on scoped features with guidance, but it also lists 4+ years of professional software-development experience and prior ServiceNow experience as requirements. Treat it as evidence of skills and practices, not as a typical fresher-eligible vacancy.
- **Requirements highlighted in the posting:** Reliable, maintainable AI-native/cloud-native software; code reviews and unit testing; Python/Java/JavaScript, databases/SQL, REST APIs, debugging, CI/CD, and ServiceNow platform development.
- **Curriculum connections:** Computer Programming (CS101), Web-Enabled Technologies (CS205), DBMS (CS206), Software Engineering (CS304), Cloud Computing (CS307), Computer Networks (CS306), Special Project (SP301).
- **Gap/opportunity:** Add assessed code reviews, unit/integration tests, API documentation, debugging and a deployment pipeline to existing software-development coursework.

## Job 3 — Digitals AI Inc., Generative AI Engineer — Freshers 2026/27

- **Link:** https://apply.workable.com/digitals/j/F81B5F03A4
- **Relevance:** The posting explicitly targets fresh graduates and early-career candidates (0–3 years) and is listed in Hyderabad.
- **Requirements highlighted in the posting:** Python; LLM applications; AI-powered SaaS; AI agents; retrieval-augmented generation (RAG); backend services and REST APIs using Python frameworks such as FastAPI, Flask or Django; practical projects/internships.
- **Curriculum connections:** Computer Programming (CS101), Industry Coding Practice (DS202), Introduction to AI and DS (DS101), Artificial Intelligence (DS201), Data Science (DS203), Machine Learning (DS304), NLP (additional subject supplied by candidate), Web-Enabled Technologies (CS205), DBMS (CS206), Cloud Computing (CS307), Special Project (SP301).
- **Gap/opportunity:** Introduce a practical AI application module covering prompt evaluation, retrieval quality, API integration, data privacy, hallucination checks, and deployment. Students should compare model output with evidence rather than trust it blindly.

## Cross-posting findings

| Recurring skill or practice | Evidence across postings | Curriculum response |
|---|---|---|
| Programming and CS fundamentals | Amazon names a programming language and data structures/algorithms or OOP; ServiceNow describes software engineering work; Digitals AI names Python. | KEEP core programming, DSA and OOP; assess them through applied assignments. |

| Projects and collaboration | Amazon values projects/internships and version control; ServiceNow describes team-based engineering; Digitals AI accepts academic projects. | KEEP internship and special project; require Git history, tests, documentation and a demonstrable product. |

## Limitations and verification

- This is a snapshot of public postings accessed on 24 October 2026; vacancies may close or change.
- The Amazon posting is explicitly early-career. The current ServiceNow posting describes scoped work with guidance but lists 4+ years and prior ServiceNow experience; it is not treated as a typical fresher role. Digitals AI explicitly accepts fresh graduates/early-career applicants.
- Requirements are summarised, not quoted in full. Use the linked original postings as the source of truth.
- These three postings are a small sample, not a complete labour-market study.
